# PN AD NETWORK — Web Migration Map

## Source of truth
- `bot-source/bot.js` — exact uploaded bot source. **Do not edit this file.**
- `bot-source/bridge.js` — exact uploaded bridge source. **Do not edit this file.**

## Where to make future web changes
- `server.js` — authentication, sessions, generic API/state routes, admin routes, application startup.
- `server/integrations/adsterra.js` — Adsterra Publisher API integration only.
- `server/modules/` — add future business-logic modules here instead of putting large logic blocks into `server.js`.
- `src/services/api.ts` — frontend HTTP/API client.
- `src/services/storage.ts` — local persistence/cache compatibility layer.
- `src/types/index.ts` — shared TypeScript domain types.
- `src/App.tsx` — routing, auth state, global application orchestration.
- `src/views/` — one file per user/admin screen.
- `.env` — secrets/configuration only. Never commit it.
- `server-seed.json` — non-secret initial application data and seeded admin metadata.

## Adsterra
The frontend must never contain the Adsterra API token. Use the server endpoints:
- `GET /api/admin/adsterra/smartlinks`
- `GET /api/admin/adsterra/report?start_date=YYYY-MM-DD&finish_date=YYYY-MM-DD`

Set `ADSTERRA_API_TOKEN` in `.env`.

## Adding a new feature
1. Add/modify the domain type in `src/types/index.ts`.
2. Add the server-side module under `server/modules/` or `server/integrations/`.
3. Add an authenticated API route in `server.js` (or a dedicated router when the API is split later).
4. Add the API wrapper in `src/services/api.ts`.
5. Add/update the relevant view under `src/views/`.
6. Update `src/App.tsx` only when navigation/global state must change.
7. Update `server-seed.json` only for safe default data.
8. Run `npm run lint && npm run build` before deployment.

## Important
The uploaded bot contains browser automation/traffic-generation logic. That source is preserved unchanged, but the web migration should use the legitimate management, account, reporting, configuration and API portions rather than implementing deceptive/fake ad-impression or traffic automation in the web application.
